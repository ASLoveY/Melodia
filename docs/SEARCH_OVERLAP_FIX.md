# v1.7.0-beta.2 搜索联想叠字修复

开启自定义背景后，搜索联想浮层沿用了页面透明底色，底层的分类、结果数量和歌曲行会穿透，和联想词叠在一起。

浮层改为独立的不透明主题 surface 底色；展开/收起保留裁切动画，移除透明度动画，避免过渡期间再次透出底层文字。应用背景图片和 35% 全页衬底设置保持原有行为。

2026-09-09 在 Android 16 / API 36 模拟器中，用真实登录状态与本地背景图输入 `rhapsody in the`，在 beta.1 复现相同叠字。覆盖安装正式签名 beta.2 后，浅色与深色主题的三条联想词均正常显示，底层分类和歌曲不再透入联想区域；选择联想词后浮层关闭，搜索结果正常显示。

258 项 JVM 单元测试通过，Android Lint 0 错误（83 警告、18 提示），正式签名构建通过。未重新安装 instrumentation 测试应用，保留现有真实登录状态；本次以同一设备的修复前后 UI 对比验收。

本次只修复搜索浮层。beta.1 记录的非空日推和实体 LDAC 验证限制仍适用，见 [LDAC 验收说明](LDAC_BETA_TESTING.md)。
