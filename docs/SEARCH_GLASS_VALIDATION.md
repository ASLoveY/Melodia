# 搜索配色与玻璃底栏

- 搜索历史使用主题主色渐变与历史图标；热搜卡片结合主色、辅助色、第三色，前三名更突出，排名独立显示。渐变文字根据底色选择黑白，渐变方向增加文字对比度。
- 底部导航改为悬浮圆角玻璃，包含背景模糊、透光、边缘高光及选中态动画。背景和页面作为模糊来源，导航文字独立绘制；底栏共享背景取色主题，列表仍通过实际底部占用高度留白。
- Android 12 及以上使用项目已有 Haze 0.6.2；旧系统降级为高不透明度的主题底色，保持导航可读、可点击。这里只描述玻璃视觉效果，不宣称物理折射。参考 [Haze API 源码](https://raw.githubusercontent.com/chrisbanes/haze/0.6.2/haze/src/commonMain/kotlin/dev/chrisbanes/haze/Haze.kt)。

验证：签名 Release 构建、JVM 回归及 Android Lint 通过。在用户要求减少测试量之后，仅补跑 4 项相关 Android 16 模拟器测试，均通过，覆盖底栏交互、创建入口、主题切换、背景取色同步、首页背景一致性；保留原测试代码。

真实账号模拟器检查了深浅搜索发现页、历史卡片跳转搜索结果、主页和音乐库导航；截图保留在忽略的 build 目录。未在本轮验证实体手机的玻璃渲染或旧 Android 系统的降级效果。
