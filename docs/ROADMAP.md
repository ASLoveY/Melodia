# 后续开发顺序

按 2026-09-07 的需求，在当前稳定性版本通过 Android 模拟器验收并发布后，依次推进：

1. **音乐库删除歌单（已实现）**：列表“更多”或网格长按进入管理；自建歌单删除、收藏歌单取消收藏均有确认和失败重试，保护“我喜欢的音乐”等特殊歌单。183 项单元测试、11 项模拟器测试通过；未对真实账号执行服务端删除。
2. **查看和修改个人资料（已实现）**：侧边栏进入资料页，查看头像和账号信息，编辑昵称、签名；先读取完整资料，保存时保留未修改字段，并以账号及资料版本校验本地写入。199 项单元测试、16 项模拟器测试通过；未对真实账号执行服务端资料修改。
3. **本地音乐文件**：通过系统文件选择器导入音频，展示元数据、接入播放队列和进度恢复，并提供搜索、排序和移出音乐库；移出音乐库不删除用户的源文件。

每项独立实现和验证。真实账号的服务端写操作与可控测试环境分开记录，本地播放应在未登录或离线时可用。
