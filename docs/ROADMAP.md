## v1.7.0-beta.3

LDAC 实验模式改用系统原生引擎并保留缓存/本地源读取、队列和统一媒体会话；OnePlus 13s / Android 16 + WF-1000XM5 已实测绕过原有 48 kHz 混音，进入 DIRECT / 96 kHz。后续覆盖更多音源与机型、长时间稳定性和耳机断连恢复；[实现与验收](NATIVE_DIRECT_OUTPUT.md)。

## v1.7.0-beta.1

35% 背景衬底、蓝牙 A2DP 高精度 PCM / LDAC 状态诊断实验、每日推荐 WEAPI 回退与空状态/登录恢复修复已实现。已用真实账号验证空日推、歌单与在线播放；非空日推及实体 LDAC 链路仍待验证，按 beta 发布。[验证记录与限制](LDAC_BETA_TESTING.md)。USB bit-perfect 仍按下方路线推进。

## 新增方向：Android Hi-Res 音频输出（待实现）

以 Android 16 为主要验收平台，覆盖 Android 14/15/17；优先官方 USB DAC 首选混音属性路线，不能仅凭系统版本或音源“Hi-Res”标签判断实际输出质量。

实施顺序：输出诊断 → 高精度 PCM 解码/输出 → USB 格式协商及可选 bit-perfect → 实体 DAC 与多厂商设备验收。高精度模式与现有交叉淡化、响度均衡分开；bit-perfect 模式停用修改 PCM 的处理，失败时明确回退。

完整依据、版本差异和验收门槛见 [Hi-Res 调研](HI_RES_AUDIO_RESEARCH.md)。该调研记录 v1.6.1 的 16-bit 路径基线；v1.7.0-beta.1 已增加蓝牙高精度路径实验，尚未验证端到端 Hi-Res 输出。

## 已完成的功能记录

按 2026-09-07 的需求，在当前稳定性版本通过 Android 模拟器验收并发布后，依次推进：

1. **音乐库删除歌单（已实现）**：列表“更多”或网格长按进入管理；自建歌单删除、收藏歌单取消收藏均有确认和失败重试，保护“我喜欢的音乐”等特殊歌单。183 项单元测试、11 项模拟器测试通过；未对真实账号执行服务端删除。
2. **查看和修改个人资料（已实现）**：侧边栏进入资料页，查看头像和账号信息，编辑昵称、签名；先读取完整资料，保存时保留未修改字段，并以账号及资料版本校验本地写入。199 项单元测试、16 项模拟器测试通过；未对真实账号执行服务端资料修改。
3. **本地音乐文件（已实现）**：通过系统文件选择器导入音频，展示元数据、接入播放队列和进度恢复，并提供搜索、排序和移出音乐库；移出音乐库不删除用户的源文件。已用真实 WAV 文件验证离线播放、去重、曲库持久化、切歌及重启续播。

每项独立实现和验证。真实账号的服务端写操作与可控测试环境分开记录，本地播放应在未登录或离线时可用。

v1.2.0 汇总：213 项单元测试、21 项模拟器测试通过；歌单删除和资料保存的请求绑定账号及会话版本，避免切换账号后误用新的 Cookie。详细范围见 [EMULATOR_VALIDATION.md](EMULATOR_VALIDATION.md)。

v1.2.1：本地音乐新增目录导入，递归扫描子目录并忽略不足 30 秒的音频；提供进度、取消、结果统计和跨文件/目录入口去重。219 项单元测试、26 项模拟器测试及真实目录验收通过。

v1.3.0：本地音乐增加长按拖选、边缘自动滚动、全选当前筛选结果、批量移出和导入目录管理；在线音乐库移除热门歌手补位及听歌排行虚拟条目，只保留个人创建/订阅/收藏内容。229 项单元测试、38 项设备测试及真实交互验收通过。

v1.4.0：新增浅色、深色、跟随系统及主题偏好持久化；提升文字对比度，修复深色默认文字和窄屏说明裁切，提供未登录设置入口。234 项单元测试、41 项设备测试及主题/播放连续性验收通过。
