# v1.7.0 正式版验收

## 发布范围

- Hi-Res 输出从 beta 纳入正式版，设置入口为“播放与缓存 → 蓝牙 Hi-Res 输出”。沿用已有开关偏好，默认关闭；开启时使用系统原生引擎，保留原有音质、缓存与本地源读取。直出能力仍取决于机型、系统和音源；此前 OnePlus 13s / Android 16 + WF-1000XM5 的 DIRECT / 96 kHz 实测见 [原生输出记录](NATIVE_DIRECT_OUTPUT.md)。
- 相似歌曲请求改用兼容的 WEAPI 路径并传入 limit/offset，过滤无效、重复和种子歌曲。漫游队列现在显示“接下来播放”并可选择歌曲；播放器不再显示内部的 `similar_roaming` 标识。
- 首页和完整播放器的漫游入口共同使用队列校验，加载期间更换歌曲或修改队列后，旧结果不能覆盖新状态。开启漫游保留当前播放位置；已有后继歌曲时不重复覆盖它们，只在尾部续接。
- 退出漫游恢复之前的顺序、模式与来源；当前漫游歌曲不在原队列时保留它，避免队列指向的歌曲与实际声音不一致。进入前的备份保存在本次运行的内存中；重启后没有原备份时，退出只将当前队列转换为普通队列。
- 本地背景图自动生成适合深浅主题的主色、辅助色和容器色，应用于首页筛选、搜索历史/热搜、音乐库筛选及其他使用主题色的按钮。取色在后台缩小采样，透明像素不会用隐藏 RGB 决定主色；按钮文字和主题强调色检查对比度。没有图片、重置背景或图片加载失败时回到默认主题，完整播放器仍使用专辑封面配色。

## 每日推荐

用户确认此前关闭了网易云个性化服务，恢复该设置后每日推荐已正常，因此本版不再改动日推请求。2026-09-11 使用模拟器内的真实账号验证：首页显示 33 首专属歌曲，日推详情正常列出 33 首，选择歌曲后 MediaSession 进入 PLAYING 且位置推进，随后暂停。该项目是设置原因确认与实际验证，不能描述为另一次日推接口修复。

## 验证结果

- 269 项 JVM 单元测试通过，包括新加的漫游并发/旧响应保护、尾部去重、重试冷却、单曲循环保护、队列模式恢复，以及多种种子色在深浅主题下的文字对比度检查。
- 71 项 Android 16 / API 36 设备测试全量通过，包括真实图片取色、深浅主题切换、排除全屏播放器的主题范围、漫游后继歌曲显示和点击索引。
- Android Lint：0 错误、83 警告、18 提示。正式签名 release 构建通过。
- 真实账号验证：日推读取和播放；相似接口返回 5 首后继歌曲，漫游队列共 6 首；开启前后的暂停位置保持，退出后恢复原日推的 33 首队列。
- 界面实测：蓝色本地测试图对应首页蓝色按钮、搜索历史/热搜的协调配色和音乐库筛选配色；深色模式切换有效。测试结束恢复模拟器原先的系统主题与默认背景。
- 设备自动化使用独立模拟器，保留真实登录模拟器的数据；没有对账号执行歌单删除、资料修改或收藏写入。原始 UI、日志与测试图保存在忽略的 build 目录。

Hi-Res 本次按用户实测无重大问题的反馈转为正式功能，未扩大既有实机结论：不承诺所有设备直出、固定 990 kbps 或端到端无损。
